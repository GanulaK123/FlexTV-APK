# GAN TV - Android App (.apk Generator)

This is a complete Android Studio project for **GAN TV**.

## How to Build & Export Installable `.apk` File
1. Download & Install **Android Studio** (Free download from developer.android.com).
2. Open Android Studio -> Select **Open** -> Choose the unzipped project folder.
3. Allow Android Studio to sync Gradle dependencies automatically (approx 1-2 mins).
4. Connect your Android Smartphone via USB (with USB Debugging turned ON in Developer Options) OR launch an Android Emulator.
5. Click the green **Play (Run)** button at the top bar to test the app on your phone immediately!
6. **To export an installable `.apk` installer**:
   - Go to top menu bar: **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)**.
   - Wait ~30 seconds. A notification popup will appear saying *"APK(s) generated successfully"*.
   - Click **locate**. Copy the generated `app-debug.apk` file to any Android device to install!
